# Log Analyzer

Учебный CLI-проект на Python для анализа серверных логов.

## Цель

Практика Python Core на приближенном к реальной backend-разработке проекте.

## Возможности

В процессе разработки программа будет уметь:

- читать лог-файлы;
- парсить строки логов;
- считать HTTP-статусы;
- находить ошибки;
- определять популярные endpoints;
- считать время ответа;
- фильтровать логи;
- обрабатывать большие файлы через генераторы.

## Стек

- Python
- pytest
